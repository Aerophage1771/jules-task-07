# Blog Home & Campaign Mockup Spec

This spec defines the copy and content structure for the blog surfaces, integrating the "There Is No LSAT Magic" social campaign.

## 1. Blog Home (`/blog`)
- **Header:** Insights, strategy, and reasoning breakdowns from GermaineTutoring.
- **Three-Card Post Index Row:** Showcasing the most recent posts.

## 2. Recent Blog Posts (3 existing)
1. **RC Question Type Map:** A deep dive into Reading Comprehension question structures.
2. **Conditional Logic Quantifier Guide:** Navigating 'some', 'most', 'many', and 'all'.
3. **Mastering the 21 LR Question Types:** A framework for routing instructions.

## 3. The 7 Next Blog Posts (Campaign: "There Is No LSAT Magic")

**Theme:** The LSAT becomes manageable when you identify the repeatable job underneath each question.

### Post 1: Everything Flaws
- **Title:** I analyzed the full range of Flaw questions so you can start seeing the recurring patterns.
- **Message:** Flaw mastery is recognizing recurring reasoning breaks, not memorizing obscure flaw names.
- **Asset:** Flaw Atlas ranking chart (Causal, Sampling, Conditional, Quantifier, Comparison, Alternative-explanation, Circular, Part-to-whole).

### Post 2: Why Learn LR Question Types?
- **Title:** If LR is just reasoning, why do I need all these question types?
- **Message:** Question types are routing instructions. The same argument requires a different approach depending on the stem.
- **Asset:** The LR Question Map (Stem -> Task -> Standard -> Operation -> Answer).

### Post 3: Complete RC Difficulty Ranking
- **Title:** Why "I'm bad at science passages" is the wrong diagnosis.
- **Message:** Difficulty has components (viewpoint shifts, abstraction, nested syntax). 
- **Asset:** RC difficulty ranking heatmap based on 22 drivers.

### Post 4: Prephrasing
- **Title:** Prephrasing is not predicting the answer.
- **Message:** Do your reasoning before the distractors influence it. (High-fidelity vs Structural vs Functional prephrase).
- **Asset:** Teaching carousel showing useful prephrasing.

### Post 5: Thinking Simply / Atomizing
- **Title:** Watch me turn an 85-word stimulus into five simple statements.
- **Message:** Complex reasoning becomes manageable when you break it into simple parts (Job -> Claims -> Roles -> Compress -> Operators -> Connect -> Gap -> Prephrase -> Verify).
- **Asset:** Screen-recorded walkthrough.

### Post 6: Useful vs. Useless Wrong Answer Journaling
- **Title:** Your Wrong Answer Journal may not be helping you improve.
- **Message:** A review is useful only if it changes a future decision. Entries must identify the exact reasoning mistake and a forward-looking rule.
- **Asset:** Before/after carousel (Weak WAJ entry vs Actionable WAJ entry).

### Post 7: There Is No LSAT Magic
- **Title:** There Is No LSAT Magic: Here Is Exactly Where My -0 Broke.
- **Message:** A strong section becomes easier to understand when you can see the decisions behind it.
- **Asset:** Full-section timed walkthrough showing the process in action under time pressure.
