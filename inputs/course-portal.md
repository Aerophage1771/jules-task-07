# Course & Student Portal Mockup Spec

This spec defines the copy and content structure for the GermaineTutoring student portal surfaces.

## Global Chrome
- **Side Nav:** Dashboard, Course, Practice, Tests, Review (Blind Review), Sessions, Homework.

## 1. Dashboard (`dashboard`)
- **Stat Tally Row:** Current metrics (e.g., questions completed, accuracy).
- **Course Progress:** Visual progress bar through the core syllabus.
- **Next-Session Brief:** Details for the upcoming tutoring session.

## 2. Learning Library (`course`, `logicalReasoning`, `readingComprehension`)
- **Logical Reasoning Wing:** LR modules, progress tracking, access to "21 Question Types".
- **Reading Comprehension Wing:** RC modules, progress tracking, access to "Difficulty Drivers".

## 3. Practice & Explanations (`practice`, `questionsBrowse`, `explanations`)
- **Question Browse:** Filterable list of LSAT questions by type and difficulty.
- **Full Explanation Page:** Detailed breakdown of a specific question, including gap analysis and correct/incorrect answer rationales.

## 4. Review & Wrong Answer Journal (`review`, `blindReview`)
- **The Centerpiece Panel:** The 5-step method strip.
- **Journal Table:** 4 columns: Identifier, Analysis, Correction, Rule for the Future.
- Includes wrong/right verdicts, rejected-choice tags, and a session tally footer.

## 5. History & Admin (`pastSessions`, `homework`, `tests`)
- Lists of completed prep tests, assigned homework sets, and past tutoring session recordings/notes.
